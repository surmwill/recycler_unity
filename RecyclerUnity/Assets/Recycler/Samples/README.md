PREREQUISITE: 
For animation purposes, these demos require the DOTween package and a reference to the DOTween asmdef. If one does not exist in your project in can be created through the DoTweenUtilityPanel: Tools -> Demigiant -> DoTween Utility Panel, and then clicking on "Create ASMDEF..."

Click the "Setup" button on the "SetupRecyclerDemos" ScriptableObject. This adds the necessary scenes to the build settings.

Play the "DemoMenu.unity" scene. This is an all encompassing demo containing a menu which allows you to navigate to and from individual functionalities.
